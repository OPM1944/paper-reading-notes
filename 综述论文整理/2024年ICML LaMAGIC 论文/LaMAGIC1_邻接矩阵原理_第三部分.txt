第三部分：LaMAGIC1 的邻接矩阵究竟是什么？

本节目标

理解 LaMAGIC1 为什么使用邻接矩阵表示电路、矩阵中的四种特殊 Token
分别代表什么，以及如何从电路网络关系构造矩阵。

核心结论： LaMAGIC1
使用矩阵描述电路的拓扑连接关系。它不是用来直接计算电压、电流的电路方程矩阵，而是一种把电路结构转换成模型可处理数据的表示方法。

1. 先理解普通邻接矩阵

在图论中，普通邻接矩阵用于表示顶点之间是否存在连接。

假设有三个顶点：

    V = {A, B, C}

连接关系为： - A 与 B 相连； - B 与 C 相连； - A 与 C 不直接相连。

那么普通邻接矩阵为：

             A  B  C
        A  [ 0  1  0 ]
        B  [ 1  0  1 ]
        C  [ 0  1  0 ]

其中： - 行表示一个顶点； - 列表示另一个顶点； - 1 表示两个顶点相连； -
0 表示两个顶点不直接相连。

普通邻接矩阵只能表达“有没有连接”。但是，LaMAGIC
研究的电路中，一个器件具有两条连接关系，因此仅使用 0 和 1 不够。

2. 为什么普通的 0/1 矩阵不够？

以双连接端器件 Sa 为例。假设：

    Net1 = {VIN, Sa}
    Net2 = {Sa, Sb, L}

Sa 通过第一条连接关系参与 Net1，通过第二条连接关系参与 Net2。

如果只用 0/1 表示，Sa 这一行只能告诉模型：Sa 与 VIN、Sb、L
存在连接。但模型不知道： - VIN 与 Sa 共享的是 Sa 的第一条连接关系； -
Sb、L 与 Sa 共享的是 Sa 的第二条连接关系。

这两组连接属于不同的电气网络，不能混为一谈。因此，LaMAGIC 需要一种比 0/1
更丰富的矩阵元素。

3. LaMAGIC 使用的四种特殊 Token

LaMAGIC 使用四种特殊 Token 表示顶点之间的连接关系：

  ------------------------------------------------------------------------------------------------
  Token                               含义
  ----------------------------------- ------------------------------------------------------------
  <no_edge>                           当前行顶点与当前列顶点不属于同一条超边，没有对应的共同网络

  <edge_1>                            两个顶点共享当前行顶点的第一条连接关系

  <edge_2>                            两个顶点共享当前行顶点的第二条连接关系

  <both_edges>                        两个顶点同时共享当前行顶点的两条连接关系
  ------------------------------------------------------------------------------------------------

特别注意： edge_1 和 edge_2
是“当前行顶点自己的局部连接编号”，不是全局统一的网络编号，也不是 MOSFET
的 D、G、S、B 引脚编号。

例如： - Sa 的 edge_1 和 Sb 的 edge_1，不一定表示同一个网络； -
同一个电气网络，在 Sa 这一行可能标记为 edge_2，在 Sb 这一行可能标记为
edge_1。

原因是每一行都从当前顶点自己的角度，对它参与的连接关系进行编号。

4. 用一个例子构造 LaMAGIC 邻接矩阵

下面用一个简化的超图例子说明构造过程。它用于解释编码规则，不应误认为是论文中的某个原始实验样本。

假设有七个顶点：

    V = [VIN, VOUT, GND, Sa, Sb, C, L]

电路包含四条电气网络：

    H1 = {VOUT, C, L}
    H2 = {VIN, Sa}
    H3 = {Sa, Sb, L}
    H4 = {GND, Sb, C}

每一条 H
都是一条超边，也就是一个电气网络。一个网络可以同时包含多个顶点。

为了构造矩阵，先确定每个顶点自己的连接关系顺序：

  顶点   参与的网络及局部编号
  ------ --------------------------
  VIN    H2 → edge_1
  VOUT   H1 → edge_1
  GND    H4 → edge_1
  Sa     H2 → edge_1；H3 → edge_2
  Sb     H4 → edge_1；H3 → edge_2
  C      H1 → edge_1；H4 → edge_2
  L      H1 → edge_1；H3 → edge_2

接下来固定矩阵的行、列顺序：

    VIN, VOUT, GND, Sa, Sb, C, L

矩阵的每个位置 A[i,j] 表示：从第 i 行顶点的角度看，它与第 j
列顶点共享哪一条连接关系。

4.1 逐行构造

VIN 行

VIN 只参与 H2，而 H2 = {VIN, Sa}。所以 VIN 与 Sa 共享 VIN
的第一条连接关系：

    VIN 行 = [N, N, N, E1, N, N, N]

VOUT 行

VOUT 参与 H1，且 H1 = {VOUT, C, L}。所以 VOUT 与 C、L 都共享 VOUT
的第一条连接关系：

    VOUT 行 = [N, N, N, N, N, E1, E1]

GND 行

GND 参与 H4，且 H4 = {GND, Sb, C}。所以 GND 与 Sb、C 都共享 GND
的第一条连接关系：

    GND 行 = [N, N, N, N, E1, E1, N]

Sa 行

Sa 参与两条网络：

    H2 = {VIN, Sa}   -> Sa 的 edge_1
    H3 = {Sa, Sb, L} -> Sa 的 edge_2

所以 VIN 与 Sa 共享 edge_1；Sb、L 与 Sa 共享 edge_2：

    Sa 行 = [E1, N, N, N, E2, N, E2]

Sb 行

Sb 参与两条网络：

    H4 = {GND, Sb, C} -> Sb 的 edge_1
    H3 = {Sa, Sb, L}  -> Sb 的 edge_2

所以 GND、C 与 Sb 共享 edge_1；Sa、L 与 Sb 共享 edge_2：

    Sb 行 = [N, N, E1, E2, N, E1, E2]

C 行

C 参与两条网络：

    H1 = {VOUT, C, L} -> C 的 edge_1
    H4 = {GND, Sb, C} -> C 的 edge_2

所以 VOUT、L 与 C 共享 edge_1；GND、Sb 与 C 共享 edge_2：

    C 行 = [N, E1, E2, N, E2, N, E1]

L 行

L 参与两条网络：

    H1 = {VOUT, C, L} -> L 的 edge_1
    H3 = {Sa, Sb, L}  -> L 的 edge_2

所以 VOUT、C 与 L 共享 edge_1；Sa、Sb 与 L 共享 edge_2：

    L 行 = [N, E1, N, E2, E2, E1, N]

5. 完整矩阵

把七行合并，得到：

顶点顺序：

    VIN, VOUT, GND, Sa, Sb, C, L

矩阵：

    A =
    [
      [N,  N,  N,  E1, N,  N,  N ],
      [N,  N,  N,  N,  N,  E1, E1],
      [N,  N,  N,  N,  E1, E1, N ],
      [E1, N,  N,  N,  E2, N,  E2],
      [N,  N,  E1, E2, N,  E1, E2],
      [N,  E1, E2, N,  E2, N,  E1],
      [N,  E1, N,  E2, E2, E1, N ]
    ]

其中：

    N  = <no_edge>
    E1 = <edge_1>
    E2 = <edge_2>

这个矩阵不是普通的 0/1 邻接矩阵，而是带有连接关系类别的超图邻接表示。

6. 为什么矩阵可能不是对称的？

普通无向图的 0/1 邻接矩阵通常是对称矩阵。

但这里的 edge_1、edge_2
是每个行顶点自己的局部编号，所以同一条电气网络在矩阵的两个方向上，标记可能不同。

例如：

    A[Sb, C] = edge_1
    A[C, Sb] = edge_2

它们并不矛盾。因为： - 从 Sb 的角度看，H4 是 Sb 的第一条连接关系； - 从
C 的角度看，H4 是 C 的第二条连接关系。

两者仍然表示同一个网络：

    H4 = {GND, Sb, C}

所以不能仅凭矩阵元素是否相等，判断两个方向是否表达同一连接。

7. <both_edges> 是什么情况？

假设两个双连接端器件 X、Y 的两条连接关系都分别属于相同的两个网络：

    Net1 = {X, Y, A}
    Net2 = {X, Y, B}

从 X 的角度看，Y 同时与 X 共享第一条和第二条连接关系，于是：

    A[X, Y] = <both_edges>

从 Y 的角度看也一样：

    A[Y, X] = <both_edges>

因此，<both_edges> 表示两个顶点同时共享当前行顶点的两条连接关系。

8. 为什么必须固定顶点顺序？

假设同一个电路有两种顶点排列：

    顺序一：VIN, VOUT, GND, Sa, Sb, C, L
    顺序二：C, L, VOUT, Sa, VIN, Sb, GND

电路的实际连接没有变化，但是矩阵的行和列会随顶点排列一起变化。

因此，同一个电路可能得到不同的矩阵序列。这会让模型把同一个拓扑误认为不同的训练目标。

为了解决这个问题，LaMAGIC
采用规范化（Canonical）的顶点顺序，并对每个顶点的连接关系采用固定排序规则，以减少同一电路因为排列不同而产生的表示差异。

9. 矩阵如何变成 Transformer 能处理的序列？

Transformer 通常接收一维 Token
序列，而不是直接把二维矩阵当作普通文本输入。

因此，LaMAGIC 按照固定顺序将矩阵逐行展开。

例如，矩阵第一行：

    N N N E1 N N N

第二行：

    N N N N N E1 E1

第三行：

    N N N N E1 E1 N

依此类推。

最终形成一维序列：

    N N N E1 N N N
    N N N N N E1 E1
    N N N N E1 E1 N
    E1 N N N E2 N E2
    N N E1 E2 N E1 E2
    N E1 E2 N E2 N E1
    N E1 N E2 E2 E1 N

实际输入输出还会包含顶点顺序、设计规格、占空比等信息。

四种特殊符号会被加入 Tokenizer 的词表，使其能够作为独立 Token
进行嵌入和预测。

训练时，模型学习根据输入的设计规格预测目标连接序列；预测出的序列再按照相同规则解码，还原成电路拓扑。

10. 本节总结

需要真正掌握以下六点：

1.  普通邻接矩阵只记录两个顶点是否相连，不能充分表达器件的不同连接关系。
2.  LaMAGIC 将电路抽象为超图，一个电气网络可以同时包含多个器件或端口。
3.  LaMAGIC 使用 <no_edge>、<edge_1>、<edge_2>、<both_edges> 四种 Token
    表达连接关系。
4.  edge_1 和 edge_2
    是当前行顶点自己的局部连接编号，不是全局网络编号，也不是 MOSFET
    的物理引脚编号。
5.  固定顶点顺序可以减少同一个电路因排列不同而产生的不同表示。
6.  矩阵按照固定顺序展开为 Token 序列，再交给 Transformer 学习和预测。

一句话概括：

LaMAGIC1
的邻接矩阵，是一种带有局部连接关系类别的超图结构编码。它不仅记录两个顶点是否存在连接，还记录它们共享当前行顶点的哪一条连接关系，从而让
Transformer 能够以序列预测的方式学习电路拓扑。

注意：本文中的七顶点、四条超边示例用于解释编码原理，不是论文原始实验电路。LaMAGIC
的具体建模假设和适用范围应以论文原文为准。
